# 0.2.1 — 2026-10-25

## Changed

- **HTTP sessions:** With `MCP_SESSION_MODE` unset, HTTP defaults to stateless; an explicit value still overrides it.
- **Source links** use the framework's `markdownLink` encoder so Markdown destinations preserve the original URL.
- **Framework errors** escape Markdown syntax in messages, recovery hints, and reasons while retaining raw structured values.
- **Framework configuration** rejects invalid numeric and timer settings at startup and names the variable, including fractional `MCP_HTTP_PORT` and negative `MCP_GC_PRESSURE_INTERVAL_MS`.
- **Hosted endpoint** is listed in registry metadata and documented with client connection examples and its personal-data redaction policy.
- **Development tooling** syncs framework skills and the security-audit classifier, which distinguishes a patched root dependency from a vulnerable transitive copy; schema acceptance tests retain their full Unicode corpus in separate field cases.
