# 0.1.1 — 2026-10-20

## Added

- **Six read-only tools** resolve airmen identity candidates and retrieve certificates, complete type ratings, informational medical fields, instructor records, remote pilot certificates, and reference guidance.
- **Local snapshot lifecycle CLI** initializes, refreshes, verifies, and inspects the monthly FAA mirror; atomic generation replacement preserves the last complete snapshot after failed refreshes.
- **Privacy controls** discard street addresses before persistence and require explicit operator opt-in for city and ZIP import, output, and filtering.
- **Local installation** supports Bun, Node.js 24+, Docker, and MCPB bundles, with snapshot provenance and source-age notices on lookup results.

## Fixed

- **CSV import** accepts embedded quotes in unquoted source fields while retaining header, width, CRC, and relationship validation ([#1](https://github.com/cyanheads/faa-airmen-registry-mcp-server/issues/1)).
- **ZIP+4 lookup** matches hyphenated and nine-digit source spellings while preserving the original value and location-access policy ([#2](https://github.com/cyanheads/faa-airmen-registry-mcp-server/issues/2)).
- **Response paging** budgets complete wire pages while preserving complete credentials and matching text/structured values ([#3](https://github.com/cyanheads/faa-airmen-registry-mcp-server/issues/3)).
- **Archive provenance** rejects redirects to a different snapshot month and records the accepted final URL ([#4](https://github.com/cyanheads/faa-airmen-registry-mcp-server/issues/4)).
- **Unknown source codes** remain undescribed raw values, including codes named like inherited object properties ([#5](https://github.com/cyanheads/faa-airmen-registry-mcp-server/issues/5)).
