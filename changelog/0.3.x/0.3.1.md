# 0.3.1 — 2026-10-29

## Added

- **`refreshState: "unreadable"`** on `faa_airmen_list_reference` topic `mirror_status` and `"refresh":{"status":"unreadable"}` on CLI `status`, for a `REFRESH.json` that can't be read or isn't a valid refresh record; the guidance names the file and says to remove it (#23).
- **Size-cut page notice** on all four list tools: a page the response size budget ended before `limit`, with more results reachable, says so in `notice` and names the `nextOffset` to continue from (#28).
- **CFII and MEI alternatives sentence** after the topic `ratings` route in zero-result notices of `faa_airmen_search_instructors` and `faa_airmen_verify_certificate`, with a retry filter where a bare code would mismatch (`certificateType: "F"`, or `instructorType` `flight` or `both`) (#26).

## Changed

- **`faa_airmen_search_instructors` zero-result notice** counts the instructors of the requested type that the name and location filters match without `ratingCodes`: a positive count routes to topic `ratings`, zero to topic `identifiers` (#26).
- **`faa_airmen_get_type_ratings`** names its scope, the pilot-file certificates (pilot, flight instructor, authorized aircraft instructor, remote pilot, flight engineer), and points to `faa_airmen_verify_certificate` mode `id` for every certificate (#25).
- **`ratingCodes`** on `faa_airmen_verify_certificate` carries the same CFII/MEI mapping as `faa_airmen_search_instructors`, from one shared string (#25).
- **Unique ID source text** (tool descriptions, `uniqueId` schema text and pattern messages, service hints) names `faa_airmen_verify_certificate`, `faa_airmen_search_instructors`, and `faa_airmen_verify_remote_pilot` (#25).
- **`faa-airmen-registry-guide` skill** 1.1: stop rule steps 1 and 4 and the CFII/MEI retry filters follow the new notices (#26, #28).

## Fixed

- **A damaged `REFRESH.json` no longer makes a serving mirror `unavailable`** (#23). Status reports `ready` with the generation's provenance, or `missing` without `CURRENT`; `prune` and `init` no longer refuse or rebuild on it, and a record of the wrong shape reports `unreadable` instead of `idle` or `running`.
- **`state` accepts only the 62 USPS codes** (#27): the 50 states, DC, PR, GU, VI, MP, AS, FM, MH, PW, AA, AE, and AP. Other two-letter codes (`ZZ`, `US`, `GB`) fail with `invalid_filter` on `faa_airmen_verify_certificate`, `faa_airmen_verify_remote_pilot`, and `faa_airmen_search_instructors` instead of returning an empty page.
