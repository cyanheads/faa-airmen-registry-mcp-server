# 0.3.0 — 2026-10-28

## Added

- **`faa-airmen-registry-guide` Agent Skill** in root `skills/`, served over MCP as `skill://faa-airmen-registry-guide/SKILL.md` (listed in `resources/list` with the `skill://{+path}` template) through `createApp({ skills: 'skills' })` (mcp-ts-core 0.13.18). It also ships in the plugins, the npm package, the `.mcpb` bundle, and the Docker image. `tools/list` is unchanged.
- **Agent Plugins root `plugin.json` and `mcp.json`**, read by Codex, Cursor, GitHub Copilot, VS Code, and Kiro (mcp-ts-core 0.13.18).
- **`lint:packaging`** validates the `skills/` tree with `validateSkillTree` and the root plugin pair (mcp-ts-core 0.13.18).
- **`docs/snapshot.md`** documents the snapshot lifecycle: commands, disk, pruning, city and ZIP, redaction.

## Changed

- **`.mcpbignore`** adds root-anchored lines for `/changelog/`, `/.claude-plugin/`, `/.codex-plugin/`, `/plugin.json`, `/mcp.json`, `/CLAUDE.md`, `/AGENTS.md`, `/.dockerignore`, `/.gitattributes`, and `/devcheck.config.json`, and replaces `/docs/idea.md` with `/docs/` (mcp-ts-core 0.13.18).
- **`scripts/clean-mcpb.ts`** strips node-gyp build output and the framework's build-only files from the bundle (mcp-ts-core 0.13.18).
- **`AGENT_DOC_ENTRY`** in `scripts/clean-mcpb.ts` and `scripts/lint-packaging.ts` is anchored to package roots (cyanheads/mcp-ts-core#794), so the MCP SDK's `dist/ext/skills/` runtime stays in the bundle. The framework's shipped cleaner would strip it, and the bundle would then fail at startup when serving skills.
- **`Dockerfile`** creates and copies `skills/` into the image; `package.json` `files` lists it.
- **`bunfig.toml`** `minimumReleaseAge` is 1 day (was 3; mcp-ts-core 0.13.17).
- **README** Getting started is reorganized around the hosted instance, a local install, and the client config; snapshot maintenance moves to `docs/snapshot.md`.
- **Framework skills and the bug report form** resynced to 0.13.18, with the new `add-skill` skill.

## Fixed

- **HTTP transport memory growth under Bun** (mcp-ts-core 0.13.17): in 0.2.1 every HTTP request retained memory through the shutdown signal, so sustained traffic grew the heap until the process ran out of memory. Each request now gets its own abort controller, released when its response ends.
- **`.mcpb` bundle contents** (mcp-ts-core 0.13.18): the 0.2.1 bundle shipped `better-sqlite3`'s node-gyp `build/` output, whose `config.gypi` records the packing machine's absolute paths, plus framework build-only files. Both are stripped; the compiled `prebuilds` stay.
